# @cratis/ai

Generated TypeScript command and query proxies for Cratis AI backend services, shared by Cratis Direct and Cratis Studio.

The package contains only generated [Cratis Arc](https://www.cratis.io/arc/) proxies and TypeScript types; it has no components or styles. Use it from an application that already has an Arc connection configured.
