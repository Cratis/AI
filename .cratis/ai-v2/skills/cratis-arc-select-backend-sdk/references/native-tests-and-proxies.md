# Match the consuming toolchain

A backend test admits only the surface it calls. When a generated proxy is requested, require the native generator to consume the actual backend contract, compile its output in the consuming project and call the disposable host. For graph discovery, check that the requested node and edge are exported. A hand-written client, a Kotlin generator test or a .NET graph screenshot cannot establish an Elixir generator or graph capability.

Keep the native build/test exit status. A wrapper that checks the matrix, matches a source string, skips unavailable tools or passes with no matching tests is not an acceptance check. If only proxy compilation passed, label runtime invocation unverified.
