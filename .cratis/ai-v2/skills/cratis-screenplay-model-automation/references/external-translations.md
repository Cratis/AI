# Translate observations at the boundary

List provider key, observed path, local concept and change condition. A polling interval schedules inspection; it does not define an event. In the fixture an unchanged directory record is seen twice, but only its addition is a fact. If the provider can delete and reuse a key, stop and agree how to distinguish successive identities before promising deduplication. For clock-triggered decisions specify a fixed instant and the state at that instant; do not rely on the test machine's clock.
