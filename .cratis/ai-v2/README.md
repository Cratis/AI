# Cratis AI corpus v2 (opt-in)

An experimental, skill-first corpus for everyday Cratis application development. It is never installed by default and shares nothing with `.cratis/ai`. Verify it with `yarn workspace @cratis/ai-verification run verify:v2` and stage it for evaluation with `stage-corpus --corpus v2`.

Start a business journey with [Design an event model](skills/cratis-modeling-design-event-model/SKILL.md). For Screenplay slices, use [Model automation](skills/cratis-screenplay-model-automation/SKILL.md) for local follow-up and [Model translation](skills/cratis-screenplay-model-translation/SKILL.md) for crossings between vocabularies.
