# Neighbouring skills

Which skill owns each task next to reverse engineering.

- Faithful migration or documentation with the source, `file:line` evidence, loss report and
  expert verification: `cratis-screenplay-legacy-extraction`.
- Greenfield discovery from interviews or documents: `cratis-screenplay-discovery`; slice
  shapes: `cratis-screenplay-slice-design`; identity and invariants:
  `cratis-screenplay-streams-and-consistency`; integrations and jobs:
  `cratis-screenplay-automations-and-translations`; coverage:
  `cratis-screenplay-scenario-coverage`.
- Editing the model through MCP: `cratis-screenplay-model-authoring`; review:
  `cratis-screenplay-model-review`; rendering and gap-fill:
  `cratis-screenplay-render-and-gap-fill`; Stage blocks and the sandbox:
  `cratis-stage-rendering-and-sandbox`.
- Syntax and verdicts: `cratis-screenplay-toolchain`; phases, identity and acceptance:
  `cratis-screenplay-modeling-lifecycle`; running Chronicle: `cratis-chronicle-cli-operations`.
