# Distinguish opening from later delivery

Subscribe to the Java `Flow.Publisher` directly and request items; prove both the first snapshot and a later one. A publisher is not required to replay state: use `ObservableState` when new subscriptions need the current value. If Java delivery works but the browser never sees it, check the Spring WebSocket handshake. For a separate dev frontend allow only its origin in `cratis.arc.observable-queries.allowed-origins` and repeat the handshake. Do not diagnose a refused connection as an empty collection.
