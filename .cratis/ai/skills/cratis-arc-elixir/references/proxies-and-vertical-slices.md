# Proxies and vertical slices

Proxy generation is opt-in. Add the compiler and every `mix compile` regenerates the
TypeScript for commands and queries:

```elixir
# mix.exs
compilers: Mix.compilers() ++ [:arc],
arc: [application: MyApp.Arc, output: "assets/src/arc"]
```

`mix arc.gen.proxies` runs it directly: `--application`, `--output`, `--layout`, `--check`
(write nothing; fail if out of date, for CI) and `--no-remove-stale`.

- One file per artifact plus an `index.ts` per folder, deterministic: generating twice gives
  identical bytes.
- Every generated file starts `// @generated by Cratis. Source: <module>. Hash: <sha256>`. **A
  file without that marker is never overwritten or removed.**
- Enums, nested lists and derived types are not generated.
- The identity details type is generated, for `useIdentity`.

## Vertical slices

Organize by feature, not by layer: the Elixir, the generated proxies and the React page of
one feature share a folder. This matches the .NET guidance.

```text
lib/samples/ticker/
  ticker.ex  queries.ex  clock.ex      # backend
  Ticker.ts  Observe.ts  index.ts      # generated
  TickerPage.tsx                       # written by hand
```

```elixir
arc: [application: Samples.Arc, output: "lib", layout: :colocated]
```

`layout: :colocated` writes each proxy in the folder of the `.ex` file that defines its module,
relative to `output`; two modules in one file share a folder; a module whose source is
outside `output` falls back to a namespace-mirroring folder. Imports between proxies are
relative and generated. The default `:namespace` layout mirrors the module namespace
under `output` after `segments_to_skip`.

Make the tooling see both: Mix and the Phoenix reloader ignore `.ts` and `.tsx`, but
**`package.json` and `node_modules` must sit above `lib`** so a slice finds `@cratis/arc` by
looking upward, and the TypeScript and bundler config must include `lib`. Keep the app shell
(`index.html`, providers, the page that picks a slice) in its own folder.

Commit the generated files so a pull request shows the contract change beside its cause, and
run `mix arc.gen.proxies --check` in CI. What several slices share (a concept, a shared read
model) lives in a shared folder; slices reach each other through commands, queries and contracts,
never internals.
