# Recover a draft without trusting the tool's guesses

**Recovering from source?** Use a trusted checkout. `cratis screenplay generate` evaluates the project; analyzing a project is not the same as reading text. MSBuild targets can execute and the intermediate output can change. Review the project, target imports, destination and intended provider first. Do not run an unfamiliar project's build graph to investigate it. For a trusted project at `src/Library/Library.csproj`, an example invocation is `cratis screenplay generate src/Library/Library.csproj --provider auto --file recovered.play` with approval to create that file. Detection covers Arc, Marten and Marten with Wolverine; resolve competing matches with the owner. An explicit `--provider` is not an isolation boundary for the adapters inside the selected provider. Inspect the generator diagnostics alongside the output. For each unrepresented rule or protection, record the original evidence and how the draft differs. Failure to bind is not permission to drop a rule, and an inferred name is not the vocabulary owner's decision.

**Recovering from observations?** Agree the service, tables, interval, data owner, environment and retention before starting a capture. Prefer synthetic traffic. Do not point an extractor at a shared database with permission to configure change capture just to see what happens. Have the DBA review replication and cleanup and limit access to the intended tables. Keep connection strings out of committed configuration. Allowlist just the needed telemetry attributes; full URLs and SQL text can disclose customer data even when no body is captured. Avoid recording secrets in the first place rather than relying on later redaction.

For an already approved local capture folder named `captures`, `cratis prologue interpret ./captures --no-llm` interprets without sending evidence to a model. Without that flag, a local setting or global provider can select model refinement. Before allowing that path, review the effective provider, endpoint, model, exact evidence and destination with the owner. A provider notice is disclosure, not consent. Inspect the resulting file locally. Correlated writes suggest a sequence, not an authorization rule or proven reason for a change. Trace reads and user-visible fields back to screens and query handlers. Mark guesses and take them to the model owner before implementation.
