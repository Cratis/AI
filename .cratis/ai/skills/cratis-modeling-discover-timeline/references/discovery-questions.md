# Questions for a missing decision

Choose the question whose answer would change the timeline. Use values from the instance under discussion, and skip questions the owner has already answered.

| Missing decision | Ask the owner |
|---|---|
| Start or end | What prompted this particular request? What did someone see or receive that told them their work was done? |
| Predecessor | What had to be true before this step? If the earlier step had never happened, could this one still have succeeded? |
| Actor or owner | Who asked, or what triggered the work? Who decides whether the request succeeds? Whose history gains a fact on success? |
| Source of a key or value | How did you know which author this was? Which values came with the request, which were known already, and which were assigned or calculated? What tied the row you saw to that author? |
| Time or order | Did these two things have to happen in that order, or did you happen to notice them in that order? What would change if they overlapped? |
| Refusal | Can you recall a request that was turned down? What made the difference? What did the caller learn and did anything change? Could a request instead succeed without changing anything? |
| Unobserved branch | You said “usually.” When does the other path apply? If nobody has seen it, who can decide what should happen? |

**What a contrasting answer changes.** Suppose the owner says, “With a blank name we ask the librarian for a name; we do not register the author.” Keep Aster's successful registration. Add a refusal branch for the otherwise identical request with a blank name: the librarian gets the prompt, no `AuthorRegistered` is recorded and no new row appears. If the owner only recalls seeing the prompt, report that observation; whether registration occurred remains open.
