# 0018 - Using Nebulit's Eventmodelers Build-Kits skills in the corpus

## Status

Accepted

Decider: woksin (Cratis), on Martin Dilger's explicit confirmation. Related: Cratis/AI#672.

## Context

Several Screenplay and event-modeling skills in this corpus draw on work by Martin Dilger and
Nebulit GmbH. Earlier material came from Nebulit's agentic-engineer repository
(https://github.com/Nebulit-GmbH/agentic-engineer), used with their explicit consent and credited in
each skill's `LICENSE` and `references/provenance.md`.

The skills in Nebulit's Eventmodelers Build-Kits repository
(https://github.com/Nebulit-GmbH/Eventmodelers-Build-Kits; the modeling-kit skills under
`eventmodelers-cli/stacks/modeling-kit/templates/.claude/skills/`, the stack build skills and the
shared skills) are now published under Creative Commons Attribution-NonCommercial 4.0. Without
further permission that licence would limit this MIT corpus to taking ideas in its own wording.

## Decision

Martin Dilger has explicitly confirmed that Cratis may use the skills in the Eventmodelers
Build-Kits repository in this corpus. Material from it is treated like agentic-engineer material:

- It may be adopted as ideas or adapted closely, expressed in Screenplay, Chronicle, Arc and Stage
  terms rather than Eventmodelers board, CLI or API mechanics.
- Each skill that uses it credits Martin Dilger and Nebulit GmbH and names the upstream skill in its
  `references/provenance.md`. A skill that adapts the material closely also states the source and
  the consent in its `LICENSE`, the same way it does for agentic-engineer.
- The confirmation covers this corpus. Redistributing the upstream files unchanged, or using them
  outside Cratis, needs its own permission.

## Consequences

Later syncs with Eventmodelers Build-Kits can adapt its skills closely instead of rewording every
idea. Credits stay mandatory; the CC BY-NC licence still applies to anyone else using that
repository.
