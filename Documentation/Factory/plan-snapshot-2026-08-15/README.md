# Factory plan snapshot — 2026-08-15

A point-in-time snapshot of the hand-authored Cratis Factory plan as it
stood on 2026-08-15. It is kept as a record of the thinking at that date,
not as current documentation.

## What this is

`CRATIS_FACTORY_PLAN.html` is a self-contained page with its images in the
sibling `CRATIS_FACTORY_PLAN.assets/` folder. Open the HTML file directly
in a browser; every reference is relative, so the page renders from a
checkout with no build step.

It links to the Factory issues it was written against, `#47` through `#66`.
Those issues are live, so the plan stays a useful map of where each stage
came from.

## Relationship to the rest of this folder

This snapshot is **not** the source of the other documents in
`Documentation/Factory/`. The two were written independently: they share
no sentences, and they use different stage taxonomies. This snapshot runs
Stage 0 through Stage 4 with Stage 1 split into 1A–1D, and folds Planner
and Studio together into Stage 3. The Factory documentation set runs
Stage 0 through Stage 5, giving Planner and Studio a stage each.

Where the two disagree, the other documents in `Documentation/Factory/`
are current and this snapshot is history.
