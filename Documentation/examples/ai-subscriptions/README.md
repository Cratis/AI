# AI subscription examples

Worked `.cratis/ai.json` examples, one file per scenario:

- `cratis-engineering.cratis-ai.json` — the single maintainer profile
  (`cratis/engineering`) with its Pi settings in `pi-settings.json`.
- `cratis-application.cratis-ai.json` — the full application composition.
- `cratis-chronicle-suite.cratis-ai.json` — the Chronicle meta-profile, no
  channel declared (the `cratis/` namespace derives it).
- `chronicle-kotlin-client.cratis-ai.json` — one language-scoped Chronicle
  cell.
- `chronicle-kotlin-language-scoped.cratis-ai.json` — the language-scoped
  cell form.
- `arc-only-application.cratis-ai.json` — Arc without Chronicle.
- `arc-react-components.cratis-ai.json` — the React + Components application.
- `specifications-library.cratis-ai.json` — a Specifications-only library.

The commands and versions in them are illustrative until a package is
published; see [updates and rollback](../../scenarios/updates-and-rollback.md)
for the current install model.
