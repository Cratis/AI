# Hand off Library author registration

`accepted.esm.json` is the export of `model` scoped to `Library.Authors.RegisterAuthor`. `registration-example.json` records its revision, input, result and dependent `Library.Authors.ListAuthors` slice. Read the top-level `revision` in `accepted.esm.json` for the excerpt. Run `screenplay export model --output library.json` and read its top-level `revision` for the full model. The listing specification belongs to the dependency, not the excerpt.

For an HTTP handoff, run `screenplay export model --format openapi --output api.json`. Under `paths`, record the method, route, `operationId` and `x-screenplay-id` for execution, validation, and `AllAuthors`. Confirm the deployed routes and host operation IDs separately in Arc's OpenAPI. Use the command's `/validate` route without executing it, and distinguish a plain query GET from a subscription that stays open for later results.

Install the fixture's Playwright and Chromium. Supply `AUTHORS_TARGET_ADAPTER` as the file URL of a trusted module exporting async `startIsolatedAuthors({revision,authorId})`. It starts an authorized, disposable Library host and returns a loopback `authorsUrl`, `editorStorageState` for the librarian, and async `close()`. Run `npm run test:journey`. It verifies the registration export before driving the shared application journey. Without the host the journey cannot run. Run the backend refusal spec separately: disabled submission is not proof of backend validation.
