# Engineering documentation authoring baseline

This protocol was frozen before execution. Persisted evidence now contains 16
model runs: eight calibration and eight held-out runs across baseline/skill
conditions, two model variants, and two repetitions. Every run used the frozen
source and prompt with tools, ambient skills, extensions, context files, and
network tools disabled.

Calibration exposed the reason vocabulary and is therefore non-diagnostic for
baseline routing value; it remains useful for output shape, authority handling,
and document-type normalization. The separate held-out prompt omits expected
decisions and reason-code mapping.

Measure document-type selection, Cratis voice, factual-source discipline,
near-miss routing, project/private-data rejection, and observable completion
separately. Structural agreement is not technical correctness, owner approval,
installation evidence, or promotion evidence.
