# Evidence-bound code review baseline protocol

This file defines a future protocol only. This change records zero model runs.

1. Freeze pilot contracts, lock, assertions, cases, fixtures, validator, grader,
   and baseline instruction before execution.
2. Give baseline and pilot identical prompt and envelope bytes.
3. Give neither condition repository, filesystem, process, tool, network,
   credential, write, approval, publication, or effect capabilities.
4. Give baseline only the result schema and a neutral bounded-review instruction.
5. Give pilot `PILOT.md` and routes, never expected results or assertions.
6. Pin model and configuration; preserve timing and run metadata separately.
7. Persist outputs only in a separately authorized evidence change.
8. Do not tune against a frozen pass.
9. Report structural validity, exact decisions, exact revision/scope binding,
   finding-set equality, evidence validity, fabricated findings, observed output
   violations, and strict canonical JSON separately.
10. Never call structural or textual agreement semantic correctness.
11. Require repetitions, held-out evidence, independent review, and effect
    telemetry before any promotion consideration.
